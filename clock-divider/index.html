Verilog HDL

module clock_divider (
    input clk,
    input reset,
    output reg clk_out
);

always @(posedge clk or posedge reset)
begin
    if (reset)
        clk_out <= 0;
    else
        clk_out <= ~clk_out;
end

endmodule

On reset, output is cleared. Otherwise, each rising edge of clk inverts clk_out. This creates a divide-by-2 clock without a counter.

How it works

1. Reset
Q is initialized to 0 (LOW).
2. Rising edge
The flip-flop captures the inverted previous Q.
3. Repeat
Q alternates 0, 1, 0, 1. Two input cycles make one output cycle.
